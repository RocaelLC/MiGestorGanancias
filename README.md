# 💰 MiGestorGanancias - Sistema Web de Punto de Venta

**MiGestorGanancias** es un sistema web desarrollado para facilitar la **gestión de ventas, productos, inventario y generación de tickets** en pequeños negocios o tiendas locales.

Su objetivo es permitir un control claro y automatizado de las transacciones comerciales, brindando herramientas para monitorear **stock, ganancias diarias y operaciones registradas**, todo desde un navegador web.

---

## 🌐 Características principales

- 🧾 Registro de ventas y generación automática de tickets
- 📦 Gestión completa de productos e inventario
- 📊 Cálculo de ganancias por día o por venta
- 📁 Historial de ventas con fecha y detalle
- 🔍 Buscador dinámico de productos y ventas
- 📅 Visualización de actividad por fechas

---

## 🛠️ Tecnologías utilizadas

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Firebase (Authentication, Firestore)
- **Base de datos**: Firestore (NoSQL)
- **Alertas y notificaciones**: SweetAlert2
- **Hosting**: Firebase Hosting
